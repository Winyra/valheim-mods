# TreeTransparency

Client-side mod that lets you toggle tree transparency on/off with a hotkey.
Useful for planning builds through dense foliage.

## Usage
- Press **F9** (configurable) to toggle transparency
- Adjust opacity via config (0.05 = nearly invisible, 1.0 = fully opaque)
- Automatically applies to newly loaded trees while active

## Config
Open the in-game config (F1 with Configuration Manager) or edit:
`BepInEx/config/winyra.treetransparency.cfg`

- `ToggleTreeTransparency` — hotkey (default F9)
- `Transparency` — opacity value (0.05–1.0)
